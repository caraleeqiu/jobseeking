**AI 素材系统 ｜ 产品经理 ｜ 2025.12 – 2026.05**
*在美图期间以兼职产品经理身份主导的 side project，完成爆款视频拆解与重构*

- 背景：针对海外广告投放团队的素材制作困境——单条素材需人工全程 2 小时，难以支撑每 3 天换一批素材的投放节奏，频繁错过热点窗口、导致投放成本抬高；负责构建爆款视频拆解与重构 AI 系统，支持海外投放业务快速响应市场变化。
- 产品规划：① 需求挖掘：调研海外广告投放团队工作流，识别两大核心痛点——流程分散、工具切换与手动搬运耗时长；AI 生成不可控、返工频繁。② 路径定义：调研 10 余款 AIGC 素材生产工具，定义产品路径（爆款解构 → 槽位替换 → 分镜编辑 → 视频输出）和双模式架构（固定工作流 + Agent 驱动节点画布）；调研市面主流视频 / 图像大模型能力，确定 Gemini + Seedance 多模型组合策略。
- 方案设计：① 语义架构：设计四层语义架构（主题 / 叙事 / 镜头 / 执行）和三态结构（原始 / 抽象 / 改写），确保数据不变、模板可复用、修改可追溯；引入身份锚点与资产槽位机制，支撑素材镜头一致性和局部替换。② Agent 架构：设计三层 Agent 闭环——任务调度器自动编排执行、节点执行器映射业务函数、LLM 决策点（规划最小工作流、多维评估、重试策略调整）；引入 Gate 审批、AB 分支对比、节点可编辑，实现"Agent 驱动、人工干预"的协作画布。③ Prompt 工程：构建 15+ Meta Prompt 模版，按四阶段管道化串联，每段输入输出结构化沉淀，支持跨阶段资产回收与替换、Bad Case 根因定位。
- 项目落地：① 原型开发：基于 FastAPI、Next.js 与 React 19 完成原型开发。② 效果评估 / 迭代：建立 QA Checklist（5 类 18 项检查点）与人机协同的测试体系，基于 Bad Case 持续迭代——针对 Inpaint 补修效果不稳定，将视觉干扰抽象为覆写槽位、实现全量资产覆盖；针对非叙事镜头的无效生成与输出缺失，建立生成 / 合并 / 风格化三维判断体系；针对多实体分析的高延迟痛点，将串行调用合并为单次矩阵化分析，耗时由 10 分钟压至 40 秒。
- 核心成果：通过链路互通和可控架构，释放约 40% 人力占用（因生成「抽卡」的不确定性，仍需人工微调），实现一周 60 条素材上新。
