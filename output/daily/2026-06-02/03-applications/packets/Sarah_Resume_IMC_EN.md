- Solution design: ① Semantic architecture — a four-layer semantic architecture (theme / narrative / shot / execution) and a three-state structure (original / abstract / rewritten) for immutable data, reusable templates, and traceable edits; identity anchors + asset-slot mechanisms for shot consistency and local replacement. ② Agent architecture — a three-layer Agent loop (task scheduler auto-orchestrating execution, node executors mapped to business functions, LLM decision points for minimal-workflow planning, multi-dimensional evaluation, and retry-strategy adjustment); gate approvals, A/B branch comparison, and editable nodes for an "Agent-driven, human-in-the-loop" canvas. ③ Prompt engineering — 15+ meta-prompt templates pipelined across four stages, with structured input/output per stage supporting cross-stage asset reuse/replacement and bad-case root-cause tracing.
- Delivery: ① Prototype built on FastAPI, Next.js, and React 19. ② Evaluation/iteration — a QA checklist (5 categories, 18 checkpoints) and a human-in-the-loop testing system; iterated on bad cases: abstracted visual noise into overwrite slots for full asset coverage when inpaint repair was unstable; built a generate/merge/stylize three-way judgment system for invalid generation and missing output on non-narrative shots; merged serial calls into a single matrixed analysis for multi-entity latency, cutting time from 10 minutes to 40 seconds.
- Outcome: through connected pipelines and a controllable architecture, freed ~40% of manual effort (human fine-tuning is still needed given the "gacha" randomness of AI generation), enabling 60 new creatives shipped per week.
